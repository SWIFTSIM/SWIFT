SWIFT Onboarding Guide
======================

This is an onboarding guide for SWIFT that can be found on
`https://swift.strw.leidenuniv.nl/onboarding.pdf`.

You will need `pdflatex` and a working TeX distribution to build it.

To build the documentation (from this directory), run ``make pdf``.
The output file will be ``onboarding.pdf``.

Note: If you want to build the document manually, note that the included images
and files are hardcoded assuming the compile command has been called from the
parent directory, i.e. the directory containing ``source/``.
