\section{What SWIFT can do}

SWIFT can solve a variety of problems aimed at cosmological and
astrophysical applications. SWIFT's features include:

\begin{itemize}
\item Hydrodynamics, using a variety of particle methods
\item Planetary science, with e.g. multiple equations of state
\item Dark Matter
\item Neutrinos
\item Gravity: self-gravity and external potentials
\item Cosmology
\item Radiative cooling
\item Radiative transfer
\item On-the-fly analysis: halo finding (FOF), power spectra
\item And more!
\end{itemize}

To enable and use these features, SWIFT needs to be compiled accordingly
and corresponding flags need to be passed at runtime. Please consult the
instructions provided in the
\href{https://swift.strw.leidenuniv.nl/docs/}{documentation}
for full details.
