\section{Running an Example}

SWIFT provides a number of examples that you can run in the \inlinecode{examples/}
directory. Many are detailed in their respective \inlinecode{README} files, and contain
python scripts (files with the suffix \inlinecode{.py} to both generate initial
conditions and plot results. The python scripts usually contain their
respective documentation at the top of the script file itself.


\subsection{Sod Shock}

In this example, we will run the 3D SodShock test. You will need to configure and
compile the code as follows:

\begin{lstlisting}[style=codeblock]
   ./configure
   make
\end{lstlisting}

\columnbreak

Then to run the code, we first download and build the
initial conditions:

\begin{lstlisting}[style=codeblock]
    cd examples/HydroTests/SodShock_3D
    ./getGlass.sh
    python3 makeIC.py
    ../../../swift --hydro --threads=4 sodShock.yml
\end{lstlisting}

We can plot the solution with the included python script
as follows:

\begin{lstlisting}[style=codeblock]
    python3 plotSolution.py 1
\end{lstlisting}

The argument \inlinecode{1} tells the python plotting script to use the snapshot with number
1 for the plot.



\subsection{Small Cosmological Volume}

As a second example, we run a small cosmolgical volume containing dark matter
only starting at redshift $z = 50$. Like for the Sod Shock example, it suffices
to configure (\inlinecode{./configure}) and compile (\inlinecode{make}) the code
without any extra flags.

After downloading the initial conditions, we run the code with cosmology and
self-gravity:

\begin{lstlisting}[style=codeblock]
    cd examples/SmallCosmoVolume/SmallCosmoVolume_DM
    ./getIC.sh
    ../../../swift --cosmology --self-gravity \
        --threads=8 small_cosmo_volume_dm.yml
\end{lstlisting}


We can plot the solution with the included python script
as follows:

\begin{lstlisting}[style=codeblock]
    python3 plotProjection.py 31
\end{lstlisting}

The \inlinecode{plotProjection.py} script requires the
\href{https://swiftsimio.readthedocs.io/en/latest/}{swiftsimio}
library.

An example containing both baryonic and dark matter is
\inlinecode{examples/SmallCosmoVolume/SmallCosmoVolume\_hydro} To run with
hydrodynamics, the \inlinecode{--hydro} flag needs to be provided as well:

\begin{lstlisting}[style=codeblock]
    ../../../swift --cosmology --self-gravity \
        --hydro --threads=8 small_cosmo_volume.yml
\end{lstlisting}
