This is the theory document for the GEAR subgrid HII photoionization
model (\code{src/feedback/GEAR/radiation.c} and related files), branch
\code{darwin/gear\_radiation}. It describes the algorithm as
implemented (Section~\ref{sec:algorithm}) and how it is wired into
\swift's task graph (Section~\ref{sec:taskgraph}); bug history,
validation results, and open work belong in the separate GEAR
radiation logbook, not here (Section~\ref{sec:scope}). Edit the
numbered \code{.tex} files
directly; each covers one topic and is short enough to update on its
own. Regenerate the PDF with \code{./run.sh}. The radiation-pressure
feedback channel and the FUV/ISRF propagation design are covered in a
separate, dedicated document in this same directory,
\code{radiation\_pressure\_isrf.tex} (\code{./run\_pressure\_isrf.sh}).
